# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through this repository's **Security** tab, using
**Report a vulnerability**. Only the maintainers can read the report.

Include what you found, where, and the steps to reproduce it. We aim to reply
within three working days. Fix deadlines follow the
[QuantumLogicsLabs severity policy](https://github.com/QuantumLogicsLabs/QuantumSecurity/blob/main/docs/severity-policy.md).

## Testing

Test only against a copy you run yourself. Do not test against our production
systems or access data that is not yours.
