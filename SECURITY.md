# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through this repository's **Security** tab, using
**Report a vulnerability**. Only the maintainers can read the report.

Include what you found, where, and the steps to reproduce it. We aim to reply
within three working days and to fix confirmed problems within the deadlines in
[docs/severity-policy.md](docs/severity-policy.md).

## Scope

This policy covers the scripts, rules, and workflows in this repository. To
report a problem in another QuantumLogicsLabs project, use the Security tab of
that project.

## Testing

Test only against a copy you run yourself. Do not test against our production
systems or access data that is not yours.
